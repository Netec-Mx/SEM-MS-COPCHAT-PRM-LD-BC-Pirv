# Práctica guiada 3. Convertir el memo en un breve deck ejecutivo, reorganizar la narrativa y realizar la revisión final de formato corporativo

## Metadatos

| Campo | Valor |
|---|---|
| Duración de práctica | **20 min** |
| Bloque previo | **4 min** — recordatorio del kit de marca |
| Transición | **1 min** |
| Tiempo total del capítulo | **25 min** |
| Complejidad | Media |
| Nivel de Bloom | Aplicar + Crear |
| Aplicación | PowerPoint con Microsoft 365 Copilot |
| Insumo | `Memo_Inversion_[Iniciales].docx` |
| Resultado | `Deck_Ejecutivo_Inversion_[Iniciales].pptx` |

## Descripción General

Crearás un deck ejecutivo breve a partir del memo validado en Word. Copilot puede generar una presentación desde un archivo de referencia, pero el contenido y el diseño deben revisarse antes de considerarlos terminados.

## Objetivos de Aprendizaje

- [ ] Crear una presentación a partir del memo del Capítulo 3.
- [ ] Reorganizar la narrativa para una audiencia ejecutiva.
- [ ] Revisar consistencia de contenido, jerarquía y formato corporativo.
- [ ] Mantener visibles los elementos pendientes de confirmar.

## Prerrequisitos

### Conocimientos requeridos

- Haber completado el memo en Word.
- Conocer el kit de marca o plantilla institucional entregada previamente.

### Acceso requerido

- PowerPoint con Microsoft 365 Copilot.
- `Memo_Inversion_[Iniciales].docx` guardado en OneDrive o SharePoint.
- Plantilla o tema corporativo, cuando corresponda.

## Entorno de Laboratorio

### Recordatorio del kit de marca — 4 min

Antes de iniciar la práctica:

- confirma la plantilla o tema correcto;
- identifica la fuente corporativa disponible;
- revisa tamaño y jerarquía de títulos;
- confirma estilos de colores y logotipo;
- no dediques tiempo a instalar el kit durante la práctica.

> [!IMPORTANT]
> Microsoft recomienda comenzar desde la plantilla de la organización cuando se crea una presentación con Copilot y se desea conservar el tema y los diseños existentes.

## Instrucciones Paso a Paso

### Paso 1: Abrir la base visual correcta

**Tiempo:** 2 min  
**Objetivo:** comenzar desde la plantilla o tema que debe conservarse.

1. Abre PowerPoint.
2. Si existe una plantilla corporativa, crea la presentación desde ella.
3. Si no existe, abre una presentación en blanco.
4. Guarda como:

```text
Deck_Ejecutivo_Inversion_[Iniciales].pptx
```

**Criterio de finalización:** el archivo está creado y utiliza el tema correcto cuando corresponde.

---

### Paso 2: Crear el primer deck desde el memo

**Tiempo:** 6 min  
**Objetivo:** transformar el documento de Word en una narrativa de presentación.

1. Abre Copilot en PowerPoint.
2. Usa la opción **crear presentación desde archivo** o su equivalente.
3. Selecciona `Memo_Inversion_[Iniciales].docx`.
4. Si tu interfaz permite agregar instrucciones, utiliza:

> **PROMPT 1 — DECK EJECUTIVO**
>
> ```text
> Crea una presentación ejecutiva breve basada únicamente en este memo.
>
> Organiza la narrativa en:
> 1. Contexto y objetivo.
> 2. Hallazgos principales.
> 3. Riesgos o puntos de atención.
> 4. Recomendación preliminar y asuntos pendientes.
> 5. Próximos pasos.
>
> No inventes datos, responsables ni decisiones que no estén en el documento fuente.
> ```

5. Espera a que Copilot genere el borrador.

**Criterio de finalización:** existe un primer deck derivado del memo.

---

### Paso 3: Revisar contenido contra la fuente

**Tiempo:** 4 min  
**Objetivo:** detectar pérdidas de contexto o afirmaciones nuevas.

Revisa diapositiva por diapositiva:

- cifras;
- riesgos;
- recomendación;
- asuntos pendientes;
- próximos pasos.

> [!WARNING]
> Si una diapositiva introduce un hecho que no está en el memo, corrígelo o elimínalo.

**Criterio de finalización:** cada mensaje importante puede rastrearse al memo.

---

### Paso 4: Reorganizar la narrativa

**Tiempo:** 4 min  
**Objetivo:** priorizar lectura ejecutiva.

Si el orden no es claro, solicita:

> **PROMPT 2 — REORDENAR**
>
> ```text
> Reorganiza la presentación para que la audiencia comprenda primero la situación, después los hallazgos, luego los riesgos y finalmente los próximos pasos.
> Mantén el contenido sustentado en el archivo fuente y no agregues información nueva.
> ```

Ajusta manualmente el orden final si es necesario.

**Criterio de finalización:** la secuencia se entiende sin leer el memo completo.

---

### Paso 5: Revisión final de formato corporativo

**Tiempo:** 4 min  
**Objetivo:** comprobar consistencia visual sin rediseñar el curso.

Verifica:

- títulos con jerarquía consistente;
- texto sin desbordamientos;
- tipografía del kit de marca;
- colores y logotipo correctos;
- ausencia de diapositivas duplicadas;
- notas o imágenes generadas por Copilot revisadas antes de conservarse.

Guarda el archivo.

**Criterio de finalización:** el deck está guardado, es legible y conserva el tema corporativo aplicable.

## Validación y Pruebas

| # | Criterio | Estado |
|---:|---|:---:|
| 1 | La presentación se creó usando el memo como fuente. | ☐ |
| 2 | Los datos y mensajes coinciden con el memo. | ☐ |
| 3 | Los asuntos pendientes no aparecen como decisiones. | ☐ |
| 4 | El orden narrativo es contexto → hallazgos → riesgos → próximos pasos. | ☐ |
| 5 | El kit de marca o tema correcto está aplicado cuando corresponde. | ☐ |

## Solución de Problemas

| Situación | Qué hacer |
|---|---|
| El memo no aparece en el selector | Confirma que está guardado y sincronizado en OneDrive o SharePoint. |
| Copilot genera demasiadas diapositivas | Elimina las redundantes y conserva solo las necesarias para la narrativa del ejercicio. |
| El formato se aleja del kit de marca | Vuelve a la plantilla/tema institucional y aplica sus diseños; evita reconstruir manualmente todo el deck. |
| Una diapositiva agrega datos nuevos | Corrígela usando el memo como única fuente o elimínala. |

## Limpieza

- Conserva `Deck_Ejecutivo_Inversion_[Iniciales].pptx`.
- Conserva el memo y el libro de Excel.
- Cierra PowerPoint cuando la sincronización haya finalizado.

## Resumen

Transformaste el memo en un deck ejecutivo y revisaste tanto la fidelidad del contenido como la consistencia visual. El deck se utilizará como apoyo contextual en la comunicación del Capítulo 5.
