# Correos del Comité de Inversiones

Los cuatro archivos `.eml` forman una única conversación cuyo asunto es:

`Comité de inversión | Revisión del portafolio y próximos pasos`

Para utilizarlos en el laboratorio, importa **los cuatro archivos juntos** en el nuevo Outlook para Windows. Consulta [`../../SETUP_GUIDE.md`](../../SETUP_GUIDE.md) para el procedimiento.
