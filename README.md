# Microsoft 365 Copilot con licencia: Productividad en Office, prompting y agentes

Formación intensiva de repaso, con progresión de nivel básico a intermedio, para reforzar el uso de Microsoft 365 Copilot dentro de Excel, Word, PowerPoint y Outlook, junto con prompting y agentes. Todas las demostraciones forman un único flujo de trabajo sobre un caso ficticio de inversión.
